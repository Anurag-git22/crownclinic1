## 🚀 How to Preview & Run

No Node.js or build tools required. Simply double-click `index.html` in your file explorer to open it in Chrome, Edge, Safari, or Firefox.

### Local Web Server (Optional):
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.
